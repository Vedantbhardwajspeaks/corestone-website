# CORESTONE INFRAVENTURES — Website

This is a complete one-page website starter for CORESTONE INFRAVENTURES PVT LTD.

## Files
- index.html — website structure/content
- style.css — design and responsive styling
- script.js — small interactions
- assets/corestone-logo.png — supplied company logo

## How to open it
1. Extract this ZIP.
2. Double-click `index.html`.
3. It opens in Chrome.

## How to publish for free
A simple option is GitHub Pages:
1. Create a free account at github.com.
2. Create a new repository.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. In repository Settings → Pages, enable deployment from the main branch.
5. GitHub gives you a free website address.
